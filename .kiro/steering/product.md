# LibreChat Product Overview

LibreChat is an open-source AI chat platform that provides a ChatGPT-like interface with enhanced features and multi-model support. It serves as a comprehensive alternative to ChatGPT Plus, allowing users to integrate multiple AI providers without subscription fees.

## Core Features

- **Multi-AI Provider Support**: Anthropic (Claude), OpenAI, Azure OpenAI, Google, AWS Bedrock, Vertex AI, and custom endpoints
- **Local & Remote AI Integration**: Compatible with Ollama, Groq, Cohere, Mistral AI, OpenRouter, Perplexity, and more
- **Code Interpreter API**: Secure sandboxed execution in Python, Node.js, Go, C/C++, Java, PHP, Rust, and Fortran
- **Agents & Tools**: No-code custom assistants with MCP (Model Context Protocol) support
- **Web Search**: Internet search integration with content scraping and result reranking
- **Generative UI**: Code artifacts for React, HTML, and Mermaid diagrams
- **Image Generation & Editing**: Text-to-image and image-to-image capabilities
- **Multimodal Support**: File uploads, image analysis, and chat with documents
- **Multi-User Authentication**: OAuth2, LDAP, email login with built-in moderation

## Target Users

- Developers seeking ChatGPT alternatives
- Organizations requiring self-hosted AI solutions
- Users wanting to avoid ChatGPT Plus subscriptions
- Teams needing multi-model AI access with custom endpoints

## Deployment Options

- Docker containerized deployment
- Local development setup
- Cloud deployment (Railway, Zeabur, Sealos)
- Self-hosted with various authentication methods
